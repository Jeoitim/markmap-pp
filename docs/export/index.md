# 导出

导出入口位于工作区顶部。导出使用当前文档内容、主题和画布状态生成文件；重要内容建议先保存源 Markdown，再导出分享格式。

## 支持的格式

| 格式 | 特点 | 推荐用途 |
| --- | --- | --- |
| Markdown | 保留源结构，可继续编辑 | 长期保存、Git 版本管理 |
| Mermaid 源文件 | 保留 Mermaid 代码结构 | 继续编辑独立 Mermaid 文档 |
| SVG | 矢量内容，任意缩放仍清晰 | 打印、排版、设计软件 |
| PDF | 静态矢量页面 | 打印、分享和归档 |
| PNG | 无损位图 | 文档、演示文稿、社交平台 |
| JPEG | 文件较小 | 快速分享和预览 |
| HTML | 独立网页，保留矢量显示 | 离线查看、网页归档 |

PDF、SVG、PNG、JPEG 和 HTML 均可导出。PDF 在 Web 端会打开打印对话框，桌面端可直接保存；PNG 和 JPEG 支持 1–4 倍渲染倍率。SVG、PDF 与 HTML 使用矢量内容，放大后仍保持清晰。

## Mermaid 文档导出

切换到 Mermaid 文档模式后，导出面板会提供 `.mmd` 源文件以及 SVG、PNG、JPEG、PDF。Mermaid PDF 使用当前图形尺寸。Markdown 中 Mermaid 代码块的预览只影响屏幕显示，Markmap 导出仍会保留原始代码块。

## 导出前检查

- 需要继续编辑时优先导出 Markdown 或 Mermaid 源文件。
- 需要印刷或在设计软件中排版时优先选择 SVG 或 PDF。
- 需要在网页中分享时选择 HTML；它不依赖编辑器运行时即可打开。
- 导图中的链接、表格、公式、代码块和 Mermaid 预览应在导出后抽查一次。

导出界面的配色属于导出主题和画布设置，不会强制跟随预览主题；文档元数据中的 `options` 仍拥有最高优先级。
