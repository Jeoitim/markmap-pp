# 编辑与思维导图

## 节点操作

单击和双击具有不同含义：单击只选中节点，双击才进入文字编辑。

| 操作 | 结果 |
| --- | --- |
| 单击节点 | 选中节点，不编辑文字 |
| 双击节点 | 编辑节点文字 |
| 编辑时按 Enter | 保存文字 |
| 选中后按 Enter | 新增同级节点 |
| 选中后按 Tab | 新增子节点 |
| Delete / Backspace | 删除选中的整个节点 |
| 点击圆点 | 折叠或展开子分支 |

如果误删或误改，点击顶部“撤回”恢复最近一次修改。

## 画布操作

- 在空白区域拖动可平移画布。
- 使用鼠标滚轮或触控板缩放。
- 点击预览右上角的适应图标，让导图重新居中并适合当前区域。
- 点击顶部全屏图标进入浏览器全屏。
- 点阵背景可在预览设置中关闭。

## 编辑器设置

编辑器右上角的设置入口提供：

- 12–22px 字号调节。
- Violet、GitHub 和 Solarized 高亮方案。
- Markdown 的源码 / 视觉（WYSIWYG）模式切换；视觉模式会实时渲染常见 Markdown 结构，浏览器会记住上次选择。
- 浏览器原生拼写检查；开启后同时作用于源码和视觉模式。
- “点击预览节点定位”；开启后点击思维导图节点会跳回对应的 Markdown 内容。
- 跟随页面的浅色或深色背景。

编辑器底部的检查状态在没有问题时显示灰色勾；发现问题时显示黄色警告和数量。点击后可以查看具体行号与说明。

当前检查覆盖常见结构问题，例如：

- 标题缺少空格。
- 标题层级跳跃。
- 列表缩进使用 Tab。
- 围栏代码块没有闭合。

## Markdown 与 Mermaid 文档

编辑器底栏的文档模式按钮可以在 Markdown 和 Mermaid 之间切换：

- Markdown 默认使用源码模式，也可以在编辑器设置中切换到实验性的视觉模式；Mermaid 文档只使用源码模式。
- Mermaid 文档拥有独立的 SVG 预览，可以导出 SVG、PNG、JPEG、PDF 或 `.mmd` 源文件。
- 如果只想在 Markdown 思维导图中查看 Mermaid 代码块，可在预览设置中开启实验性的“Mermaid 代码块预览”。它会把 `mermaid` 围栏显示为 SVG 缩略图，并提供复制源码、全屏查看和下载 SVG；导出思维导图时仍保留原始代码块。

## 预览设置

预览右上角设置入口支持：

- 调整节点字号。
- 选择思源黑体、思源宋体、霞鹜文楷、Inter Variable 或 JetBrains Mono Variable。
- 调整支持字体的可变字重。
- 显示或隐藏点阵背景。

## 仓库笔记链接

仓库内链接仍使用标准 Markdown，但应用会根据目标类型区分导航行为：

```md
[仓库根目录下的文档](/doc/说明.md)
[相邻笔记的某个标题](./设计.md#交互原则)
[当前笔记的标题](#节点操作)
[普通网站](https://example.com)
```

前三种指向 Markdown 文件或当前标题的链接会在应用内打开，并同时定位编辑器行与导图节点。普通网页、邮箱和其他协议链接不会被接管，仍由浏览器打开。

在编辑器或导图预览中选中文字后右键，可以直接复制、剪切、粘贴，或从仓库文件树选择目标笔记。文件默认只显示一行，点击左侧箭头后才展开它的标题层级；搜索仍可同时匹配文件和标题。菜单底部的“更多浏览器选项”会让下一次右键显示浏览器原生菜单；也可以随时按住 Shift 再右键。

打开 Markdown 编辑器底栏中、设置按钮旁的链环图标，可以查看：

- 哪些笔记链接到当前文件。
- 当前文件链接到了哪些笔记和标题。
- 不存在的文件或标题。
- 已索引笔记数；需要完整结果时可选择“索引全部”。

移动或重命名仓库文件时，已读取到本地的 Markdown 引用会自动更新，并作为本地修改等待下一次同步。

## 桌面端布局

拖动中间分割线可改变编辑器与预览比例。分割线上的独立长条按钮用于收起或展开编辑区；预览始终保留。

仓库文件树的文字和图标会跟随编辑器字号，并通过灰色缩进线显示目录层级。

## 移动端

窄屏下使用顶部页签在 Markdown 和思维导图之间切换。建议横屏查看较大的导图；编辑后切到预览即可检查结构。

手机长按文本时继续使用系统选中栏，因此全选、查词等系统能力不会被自定义菜单遮挡。markmap++ 的移动浮动操作只补充笔记链接；视觉模式选中标题后，底部操作栏可以复制、转为段落、删除或切换标题层级。移动端点击仓库文件会自动切回编辑器，长按文件树仍保留仓库文件菜单。
