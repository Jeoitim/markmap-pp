# 版本 Log

这里记录已经发布或进入稳定基线的主要变化。日常修复会随对应版本一起归档；当前安装包版本与下载入口请查看[Web 与桌面 App](/app/)。

## 1.2.2

编辑器、导出和跨端快捷键继续完善：

- 编辑菜单新增重做、复制、剪切、粘贴、删除和全选，并在源码 / 视觉模式下统一处理编辑命令。
- 偏好设置支持 `Ctrl+,` 打开；新增快捷键管理页，可以自定义、恢复或禁用快捷键，并用感叹号标记冲突。网页端“打开文件…”使用 `Ctrl+O`，与有序列表快捷键分开。
- 视觉 Markdown 编辑器补齐行内与块级 KaTeX 公式显示；区块转换菜单支持标题层级、数学公式、代码块、引用、有序列表、无序列表和任务列表，并保留表格的增删行列操作。
- 选中文字气泡和移动端底栏支持链接、粗体、斜体、下划线、行内代码、文字颜色与荧光标记；颜色预设支持经典、马卡龙和莫兰迪色系，可修改并恢复预设。
- 导出主题可跟随当前主题，也可以单独选择预设；Solarized Light 与 Everforest Light 的导出配色分开处理，正文、链接、代码块和任务框颜色会同步主题语义。
- 移除视觉模式中不支持正常渲染的“转换为 HTML 块”入口，避免将 HTML 伪装成代码文本区块。

## 1.2.1

Agent、跨端编辑器和桌面窗口体验进一步完善：

- Agent 新增 Anthropic Messages、OpenAI Chat Completions、OpenAI Responses API 和 Gemini Native `generateContent` 的上游格式选择，并按服务商、Base URL、模型和搜索开关计算默认接口。
- 联网搜索新增 OpenAI、Anthropic、Gemini、MiMo、Azure OpenAI、DeepSeek、Groq 和 Moonshot / Kimi 的原生协议适配；Agent 会解析可用的引用、URL、grounding 来源和搜索操作。
- MiMo 增加 `force_search` 开关；搜索协议、模型识别、来源是否可展示以及服务商插件和权限限制已在 [Agent 指南](/agent/) 中说明。
- 优化视觉 Markdown 编辑器的 Notion 式区块操作、标题层级转换、格式气泡和移动端底栏，同时保留系统右键中的复制、粘贴等原生能力。
- 修正主题对正文、超链接、代码块背景和 Markmap 预览颜色的传递；未显式指定的代码块文字会继承主题文字色。
- Electron 偏好设置 > 全局新增“标题栏使用系统材质”，默认开启；Windows 使用 Mica，macOS 使用透明模糊标题栏，也可以关闭后切回普通窗口背景。

## 1.2.0

主题系统和可访问性进入稳定版本：

- 新增社区配色主题体系，包括 Catppuccin、Everforest、Gruvbox、Tokyo Night、Nord、Dracula 等，保留主题原名和配色语义。
- 偏好设置集中管理编辑器、预览、外观、拼写、全局和快捷键；移动端使用可展开分类，桌面端使用侧栏布局。
- 主题预设默认同时管理 UI、编辑器和预览；可以单独打开“语法高亮”或“画布背景”覆盖，让高亮和画布背景脱离主题切换。
- 深色 / 浅色主题支持跟随系统，也可以手动切换默认主题；导出界面保持独立的配色逻辑。
- Markmap 分支线会根据背景自动调整明度以改善对比度；文档元数据中的 `options.color` 始终拥有最高优先级。
- Agent 入口、选中态和工作区控件纳入主题色管理。

## 1.1.0

编辑体验和多端行为完成一轮整理：

- 新增 Mermaid 文档模式、代码块预览和 Mermaid 源文件导出。
- 新增实验性的 WYSIWYG 视觉编辑器，并记忆浏览器上次使用的源码 / 视觉模式。
- 移动端保留系统文本选中栏，支持原生全选、查词等能力；仓库文件点击后可以进入编辑器。
- 移动端编辑操作栏和标题层级气泡重新布局，桌面端恢复标题右侧浮动操作。
- GitHub 文件列表、编辑器导航、拼写检查和偏好设置得到补充；桌面端增加窗口与本地文件工作区能力。
- 新增静态矢量 PDF 导出，并改善字体、表格、公式和 Mermaid 预览的导出一致性。

## 1.0.x

- 建立 Markdown 到可编辑 SVG 思维导图的工作流。
- 提供节点增删改、画布缩放、链接、表格、公式、代码块和多格式导出。
- 建立 Web、Electron 与移动端共享的本地工作区，以及 GitHub 仓库同步基础。
